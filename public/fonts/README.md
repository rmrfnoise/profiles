# Bundled fonts

- **Noto Sans SC** — Chinese body, labels, forms, and UI text.
- **Noto Serif SC** — Chinese names, display numbers, and dialog titles.

Source: [Google Fonts](https://fonts.google.com/) / [Noto CJK](https://github.com/notofonts/noto-cjk).

Both families are distributed under the **SIL Open Font License 1.1**. The files in `noto-sans-sc/` and `noto-serif-sc/` are WOFF2 unicode-range subsets generated by Google Fonts; `noto.css` maps them locally. No font is requested from the network at runtime.
